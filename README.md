# Group A Professional Portfolio

This repository contains the Group A project for SWE2106 Internet Technologies and Web Design.

The project is a five-page professional portfolio built with semantic HTML5. It demonstrates page structure, accessibility, multimedia, lists, tables, forms and Git collaboration.

## Pages

- `index.html` - Home
- `about.html` - About
- `gallery.html` - Gallery
- `data.html` - Data
- `contact.html` - Contact

## Project Folders

- `design/` - sitemap, wireframes and design document
- `images/` - images used in the portfolio
- `videos/` - videos used in the gallery
