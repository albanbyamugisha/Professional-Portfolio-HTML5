Technical Terminology

HTML5
HTML5 is used to create and structure the content of a web page.
CSS
CSS is used to control the appearance and layout of a website.
JavaScript
JavaScript is a programming language used to add interaction to web pages.
Git
Git is a version control system used to track changes made to code.
GitHub
GitHub is an online platform used to store code and support collaborative development.
Semantic HTML
Semantic HTML means using meaningful elements such as header, nav, main, section, article, aside and footer.
