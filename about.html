Technical Terminology

HTML5
HTML5 is used to create and structure the content of a web page.
CSS
CSS is used to add styles and control the appearance of a website.
JavaScript
JavaScript is a programming language used to make websites interactive.
Git
Git is a version control system used to track changes made to computer code.
GitHub
GitHub is an online platform used to store code and allow developers to work together.
Semantic HTML
Semantic HTML means using meaningful HTML elements such as header, nav, main, section and footer.
